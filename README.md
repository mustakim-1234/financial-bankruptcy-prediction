## 📌 Project Overview

Financial bankruptcy prediction is an important problem for banks, investors, and financial institutions. This project develops a Machine Learning classification model to predict whether a company is likely to become bankrupt based on its financial indicators.

The project demonstrates an end-to-end machine learning workflow including data preprocessing, exploratory data analysis (EDA), feature engineering, handling class imbalance, model comparison, hyperparameter tuning, and model evaluation.

---

## 🎯 Objectives

- Predict whether a company will become bankrupt.
- Analyze financial indicators affecting bankruptcy.
- Compare multiple machine learning algorithms.
- Improve prediction performance using hyperparameter tuning.

## 🏆 Best Model Performance

| Metric | Score |
|---------|-------|
| Accuracy | **85.23%** |
| Precision | **82.98%** |
| Recall | **88.64%** |
| F1-Score | **85.71%** |

---

## 📈 Key Results

- Reduced features from **95** to **79** using feature selection.
- Addressed class imbalance using undersampling.
- Compared seven machine learning algorithms.
- Selected Random Forest as the best-performing model after tuning.
- Achieved a balanced performance across Accuracy, Precision, Recall, and F1-Score.
