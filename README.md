## Project Overview

Financial institutions and investors face significant risks when companies become bankrupt. This project develops a Machine Learning model capable of predicting corporate bankruptcy using financial indicators.

The complete workflow includes data preprocessing, feature selection, exploratory data analysis (EDA), model comparison, hyperparameter tuning, and performance evaluation.

---

## Problem Statement

Predict whether a company is likely to become bankrupt based on its financial statements.

---

## Dataset

- Companies: 6,819
- Original Features: 95
- Final Features: 79
- Target Variable:
  - 0 → Non-Bankrupt
  - 1 → Bankrupt
